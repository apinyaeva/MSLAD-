# MSLAD: Multi-Scale Latent Attention Diffusion for Finance

## Обзор проекта
Данный репозиторий содержит программную реализацию магистерской диссертации на тему **«Применение диффузионных нейронных сетей в финансах»**. 

**MSLAD (Multi-Scale Latent Attention Diffusion)** — это гибридная генеративная архитектура, разработанная для синтеза реалистичных финансовых лог-доходностей. Модель комбинирует мультимасштабные сверточные слои для извлечения паттернов волатильности и механизмы Multi-head Attention для фиксации долгосрочных временных зависимостей.



##  Ключевые особенности
* **Multi-Scale Encoding:** Использование параллельных ядер свертки (k=3 и k=11) для анализа микро-динамики и макро-трендов.
* **Temporal Attention:** Механизм внимания (4 головы) для воспроизведения эффекта кластеризации волатильности.
* **Latent Diffusion:** Генерация в сжатом пространстве признаков, что обеспечивает высокую скорость инференса и стабильность обучения.
* **Lightweight:** Всего **9 825** обучаемых параметров (Params size: 0.02 MB).
